What is HTML?

HTML is a webpage programming language developed by Tim Berners-Lee, an English Computer-Scientist. It is used for webpage development, and consists of semantic elements such as buttons and textarea tags, and non-semantic elements like span and div tags. HTML works beside two other programming languages, CSS and JavaScript. HTML defines the structure, CSS defines the styling adn JavaScript makes it interactive.

What are semantic and non-semantic elements?

A semantic element is a HTML element where the tag clearly describes the role of the element (e.g. buttons, images, headers). A non-semantic element is where the tag of that element does not clearly describe the use and role of the element (e.g. div or span tags). These are container elements.

What does HTML stand for?

HTML stands for Hyper Text Markup Languaage It's a markup language, meaning it doesn't act on logic and variables like Python or C#, it's there to define the core structure of a webpage.

Tags, Elements and Void Elements

In HTML, an element is the actual thing that appears on the page, like a button or a piece of text. A tag is the code used to write the element, for example <button> or <p>. There are two types of tags: void and non-void elements. A void element is an element which cannot have child elements nested in it and does not have a closing tag. A non-void element can and has a closing tag, such as </button>.
